Autoposter Tiktok

Autoposter Tiktok is a personal desktop tool. It takes videos created by its owner, converts them to TikTok's vertical format (1080x1920), writes a caption and uploads them to the owner's own TikTok account as drafts (inbox) through the official TikTok Content Posting API. The owner then reviews and publishes each draft manually in the TikTok app.

It is not a public service: it runs only on the owner's computer and is used only with the owner's account.
